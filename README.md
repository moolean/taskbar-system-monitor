# Taskbar System Monitor 2

轻量、无第三方依赖的 Windows 资源栏。默认直接显示 CPU、内存、下载和上传速度，无需点开面板。

![资源栏渲染预览：示例数据，并非桌面截图](docs/taskbar-preview.png)

## 这次重新设计了什么

旧版把窗口嵌进 Explorer，尝试裁剪任务栏按钮区域，容易在系统重新布局时发生重叠。2.0 移除了这些代码，改用 Windows Shell 的 AppBar 接口，**在主屏幕底部、任务栏上方预留独立的一整行空间**。它不是原任务栏内部的小部件；代价是桌面可用高度减少一行。

- 默认 24 逻辑像素高、9 pt 常规字体；系统 125% 缩放时为 30 实际像素。
- 不透明的浅色 / 深色柔和背景，自动跟随系统，可手动选择主题或关闭渐变。每次重绘完整背景，不采集屏幕底色、不使用透明色键。
- 右键资源栏或点击末尾 `···` 打开设置，提供即时示例预览。
- 可选 CPU 使用率、内存使用率、已用 / 总内存、下载、上传、电量、时间。
- 可调字号（8–11 pt）、高度（24 / 28 / 32）、左右 / 居中对齐、刷新间隔（1 / 2 / 5 秒）、网络网卡。
- 空间不足时隐藏放不下的项目，右端显示 `+N`；详细数据仍可在面板和悬停提示中查看。
- 关闭资源栏可保留托盘入口；重复启动会打开已有实例的面板。设置写入本地 XML，重启后保留。
- 首次运行启用当前用户开机自启，之后可以从托盘菜单关闭。
- 隐藏 / 正常退出时释放 AppBar 空间。无需管理员权限、无常驻服务、无遥测。

## 系统要求

Windows 10 / 11，.NET Framework 4.8。当前仅支持**主屏幕底部**资源栏，不在所有显示器上重复显示，也不跟随纵向任务栏移动。硬件温度、GPU、逐进程网速暂不支持。

自动网络模式选择一张带网关的活动网卡，不是所有网卡流量的总和；VPN 或多网卡环境可手动指定。首次采样、网卡切换或计数器重置时显示 `—`，不冒充 0。无电池的设备显示“无电池”。

## 安装和运行

在项目目录的 PowerShell 中运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

脚本每次都重新构建，优雅停止已知安装路径的旧实例，将 EXE 安装到 `%LOCALAPPDATA%\TaskbarSystemMonitor`，登记当前用户开机启动并运行。升级保留配置和上一份 EXE。若 1.x 旧实例无法退出，请先从它的托盘菜单退出再重试；脚本不会强杀它或重启 Explorer。

只构建、不安装：

```powershell
.\build.ps1
.\dist\TaskbarSystemMonitor.exe
```

便携运行首次也会登记当前位置的开机启动；移动 EXE 后请在托盘菜单中重新启用该选项。

## 操作

- 资源栏左键：详细面板；右键 / `···`：设置。
- 托盘图标左键：面板；右键：设置、显示 / 隐藏、自启、任务管理器和退出。
- 面板右下角也有“设置…”按钮。关闭面板只隐藏它，彻底退出请用托盘菜单。
- 隐藏资源栏：设置里取消“任务栏上方独立栏”。
- 配置：`%LOCALAPPDATA%\TaskbarSystemMonitor\settings.xml`；错误日志同目录 `error.log`。

## 验证

```powershell
.\test.ps1
# 需真实桌面和 Explorer，先从托盘菜单退出正在运行的监控器：
.\test.ps1 -Desktop
```

普通测试覆盖采样边界、网速计数器、XML 替换保存，以及 100% / 125% / 150% / 200% DPI 下的 108 组排版组合。桌面测试会短暂显示一个最大化测试窗口，验证预留空间、重复定位、改高度、隐藏再显示和退出恢复，然后移除测试窗口及资源栏。

2026-09-14 本机实测结果及未验证范围见 [验证记录](docs/validation.md)。桌面测试不能用 CI 的离屏渲染测试代替。

## 卸载

```powershell
.\uninstall.ps1
# 同时删除本程序配置、错误日志：
.\uninstall.ps1 -PurgeSettings
```

默认只删除本程序 EXE / 升级备份和自启项，保留设置。不会递归删除目录内的其他文件。

## 开发与隐私

源码在 `src/`；`build.ps1` 使用 Windows 自带的 C# 编译器，不需要额外安装 SDK。也可用支持 .NET Framework 4.8 的 Visual Studio / .NET SDK 构建 `TaskbarSystemMonitor.csproj`。GitHub Actions 构建并运行普通测试，EXE 保存在 Actions 工件中。

程序仅读取本机 CPU、物理内存、网络接口计数器、电池状态与时间，不主动请求网络、不上传数据。
