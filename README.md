# Taskbar System Monitor 3.1 · 信息工作台

把任务栏上方的一行变成可配置的工作信息栏：系统资源、Codex 额度、下一场会议、网络信息、工作追踪和时间。会议与工作摘要自动伸展，点击模块展开详情。

![浅色与深色样式预览，所有内容均为示例数据](docs/taskbar-preview.png)

上图为代码渲染的**示例**，不包含真实会议、工作项或 IP。程序未连接数据源时会明确显示状态，不拿示例数据填充实时信息。

## 模块

| 模块 | 常驻信息 | 点击后 |
| --- | --- | --- |
| CPU / 内存 / 上传 / 下载 | 本机实时统计 | 资源面板与历史 |
| Codex | 实际额度窗口的剩余比例 | 全部返回的额度桶、重置时间、刷新 |
| 飞书日历 | 下一场或进行中的会议、开始时间与倒计时 | 日程列表、地点、内容和日程提供的链接 |
| IP / 位置 | 默认仅本地 IP；经用户启用后可显示公网出口与大致位置 | 网卡、来源和更新时间 |
| 工作追踪 | 最多三项未完成工作的标题、状态 / 进度 | 全部工作项、详细笔记、编辑和链接 |
| 日期 / 时间 / 电量 | 可选基础信息 | 资源面板 |

右键信息栏或点击末尾 `···` → 设置。新版设置采用中性色侧栏、分组卡片和固定底部预览，分为“常规与显示 / 外观 / 数据连接 / 工作追踪”四页，长内容可以滚动。可以启用 / 隐藏模块、上下排序、修改字号、高度、对齐与采样间隔。工作项在“工作追踪”页添加；完成项保留在详情中，不占用摘要。

## 一行空间与外观

- 使用 Windows Shell AppBar 正式接口，在**主屏幕底部、任务栏上方预留一整行**。不是嵌入原任务栏；桌面可用高度会减少这一行。
- 默认 24 逻辑像素，125% 缩放时是 30 实际像素；9 pt 常规字体。可选 24 / 28 / 32 高度、8–11 pt 字号。
- 默认利用整行宽度，日程和工作区吸收多余空间。较窄屏幕折叠放不下的模块，末尾 `+N` 表示数量。
- 跟随系统明暗与强调色，也可选择雾蓝、淡紫、青玉。使用低饱和背景、细分隔和悬停色块，与任务栏保持色彩呼应。
- 背景完整重绘、不透明，不截取屏幕底色，不裁剪 / 移动 Explorer 的应用按钮。
- 隐藏 / 正常退出释放预留空间；仅托盘模式下重复启动仍能打开面板。
- **默认不置顶**，允许普通窗口覆盖信息栏。可在“常规与显示”选择“保持在普通窗口上方”；全屏时让位，退出全屏仍尊重该开关，不会偷偷恢复置顶。

## 数据连接

### Codex

每 5 分钟启动一个短暂的本地 `codex app-server --stdio`，完成初始化后只调用 `account/rateLimits/read`，随后关闭私有子进程。自动寻找 `codex.exe`，也可在设置指定路径。

使用 **CLI 当前登录的 ChatGPT 账户**。如果它与桌面应用登录不同，显示的额度也可能不同；API-key-only 登录可能没有 ChatGPT 额度。程序不直接打开登录令牌文件，不创建任务，不调用重置额度、登录、退出登录或消费类接口。缺失窗口不显示为 100%；按服务端的 `windowDurationMins` 标注窗口。

接口依据：[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。

### 飞书日历

在飞书的日历设置里生成 **CalDAV 专用账户**，将服务器、专用账号、专用密码填入本程序“数据连接”。不要填飞书登录密码，也不需要把凭据发到聊天或仓库。企业管理员可能禁用该功能。

先点“测试连接”，再点“保存更改”。测试会显示发现账户、发现目录、读取日程或解析日程的具体失败阶段；HTTP 401、403、405 等状态会给出不同说明，不把权限或协议错误一概说成密码错误。服务器地址可以直接粘贴 `caldav.feishu.cn`，程序会补齐 HTTPS；密码输入留空保留已保存的密码，测试不会自动保存输入。

本程序使用 PROPFIND / REPORT 只读同步未来 14 天，每 2 分钟刷新；不创建、编辑或删除会议。凭据用 Windows DPAPI 当前用户加密后保存，跨用户不能直接解密。取消日程被排除，支持 UTC、系统时区及常见时区映射；请求服务器展开重复日程，未展开或无法可靠解析时明确报错。最多跟随三次同源 HTTPS 跳转，保留 DAV 方法；跨服务器地址不会转发凭据。相对日历路径按返回它的目录解析，DAV 内部错误不会当作“暂无日程”。

**目前没有使用真实飞书凭据完成端到端验证**；协议、解析和凭据保护测试已通过，具体租户的 CalDAV 能力仍需连接后确认。

依据：[飞书官方同步说明](https://www.feishu.cn/hc/zh-CN/articles/665183342590-%E5%90%8C%E6%AD%A5%E7%AC%AC%E4%B8%89%E6%96%B9%E6%97%A5%E5%8E%86%E4%B8%8E%E9%A3%9E%E4%B9%A6%E6%97%A5%E5%8E%86)。

### IP 和大致位置

默认关闭公网查询，仅从本机网卡读取内网 IP。设置中明确开启后，每 10 分钟通过 HTTPS 请求 `ipwho.is`；该第三方因此获得公网出口 IP，并返回大致城市 / 网络位置。**不是 GPS 定位**，代理或 VPN 会改变结果。不会发送会议、工作笔记或 Codex 数据。

关闭查询时不调用该服务；网络失败时保留本地 IP 并显示失败说明。服务能力和限制以 [供应商文档](https://ipwhois.io/documentation) 为准。

## 安装

要求 Windows 10 / 11、.NET Framework 4.8，不需要第三方运行库或管理员权限。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

每次重新构建后优雅停止旧实例，安装到 `%LOCALAPPDATA%\TaskbarSystemMonitor`，保留配置与上一份 EXE，登记当前用户开机自启并运行。1.x 无法优雅退出时先从旧版托盘菜单退出；脚本不强杀 Explorer 或监控器。

```powershell
# 只构建、便携运行
.\build.ps1
.\dist\TaskbarSystemMonitor.exe
# 定位某个模块；已有实例时不会重复启动
.\dist\TaskbarSystemMonitor.exe --module=Codex
# 可选：Calendar、Ip、Tracks、Settings
```

首次便携运行也会登记当前位置的开机自启；移动 EXE 后可从托盘菜单重新启用。配置与工作项位于 `%LOCALAPPDATA%\TaskbarSystemMonitor\settings.xml`，请不要上传真实配置。

## 验证与边界

```powershell
.\test.ps1
# 退出正在运行的监控器后，在真实 Explorer 桌面执行：
.\test.ps1 -Desktop
# 用已保存的账户只读诊断，报告不含密码或会议内容：
.\dist\TaskbarSystemMonitor.exe --calendar-test=dist\calendar-test.txt
# 使用空白临时配置打开设置界面，不保存真实配置：
.\dist\TaskbarSystemMonitor.exe --settings-test=dist\settings-test.txt
```

测试覆盖采样、108 组 DPI / 排版组合、满宽布局、额度计算、设置与工作项保存、凭据加密、日历时区 / 取消 / 折行、跨域保护与链接限制，以及模拟 CalDAV 服务的目录发现、相对路径、REPORT 和错误分类。桌面测试验证最大化窗口不进入信息栏、反复定位无漂移、改高度、隐藏再显示和退出恢复，并检查真实窗口置顶样式与模拟全屏通知后的恢复。

实际验证与未测范围见 [验证记录](docs/validation.md)。目前仅在主屏底部显示；不支持多屏各放一条、硬件温度、GPU 或逐进程网速。对话框首次按所在屏 DPI 缩放，运行中跨屏改变 DPI 尚未验证。飞书账号接入和公网位置请求未完成实机端到端验证。

## 卸载和隐私

```powershell
.\uninstall.ps1
# 同时删除本程序配置 / 工作项 / 凭据 / 错误日志：
.\uninstall.ps1 -PurgeSettings
```

默认保留设置，只删除本程序 EXE、升级备份和自启项；不递归删除其他文件。工作项始终只保存在本机。外部数据源仅在相应模块和连接选项启用时读取；无广告、无遥测。

源码在 `src/`，Windows 自带 C# 编译器可构建。GitHub Actions 提供自检与 EXE 工件。采用 [MIT](LICENSE) 许可证。
